# تنگه هرمز | بازگشایی تنگه

یک بازی آفلاین اندروید دربارهٔ ادارهٔ بندر و رساندن کاروان‌ها به اسکله. بازیکن کرایهٔ عبور کشتی‌ها را می‌گیرد، نفت می‌فروشد و از درآمدش برای ساخت بندر و چراغ‌های مسیر استفاده می‌کند. در آبراه می‌تواند زمان تاباندن نور، اولویت نشان‌ها و آرایش فانوس‌ها را انتخاب کند.

نسخهٔ ۱٫۰٫۰ شامل ۴۵ عملیات در سه منطقه، هفت شکل آبراه، چهار نوع ایستگاه، چهار طرح توسعهٔ منطقه‌ای و ۲۰ سفارش با دو روش حمل برای هر سفارش است. تمرین از لحظهٔ ورود در دسترس است. سفر هفتگی با تجهیزات یکسان و رکورد روی دستگاه اجرا می‌شود. باز کردن شیفت بی‌پایان و شروع دوبارهٔ داوطلبانه از هدف‌های پایان کارزارند.

## ساخت اندروید

Node.js 24، JDK 21، Android SDK 36 و Build Tools 35.0.0 را آماده کنید.

```bash
npm ci
npm run verify
npm run build:android
bash android/gradlew -p android assembleDebug assemblePreview assembleRelease bundleRelease lintDebug
```

بستهٔ بازی `ir.hormuz.sovereign` و کد نسخه ۱۰۰ است. فایل‌ها زیر `android/app/build/outputs/` ساخته می‌شوند. برای امضای انتشار، متغیرهای `HORMUZ_KEYSTORE`، `HORMUZ_STORE_PASSWORD`، `HORMUZ_KEY_ALIAS` و `HORMUZ_KEY_PASSWORD` را در محیط خصوصی ساخت تنظیم کنید. برای به‌روزرسانی نسخهٔ منتشرشده از کلید مورد پذیرش همان مارکت استفاده کنید.

پیش‌نمایش قابل نصب با شناسهٔ جداگانهٔ `ir.hormuz.sovereign.preview` در کنار نصب قدیمی می‌ماند. فایل پشتیبان صادرشده از نسخهٔ ۰٫۷ را می‌توانید از تنظیمات وارد کنید.

## آزمون

`npm run verify` منطق کمپین، صنعت، دفتر مالی، ساعت بازی، ذخیره و مهاجرت را بررسی می‌کند. برای آزمون رابط، پس از ساخت اندروید، محتوای `android-web/` را با یک سرور محلی در دسترس قرار دهید و دستور زیر را با نشانی سرور و مسیر Chromium نصب‌شده اجرا کنید.

```bash
TEST_URL=http://127.0.0.1:4173 AUDIT_CHROMIUM=/usr/bin/chromium npm run test:mobile
```

فرمان زیر یک APK آزمایشی قابل بازرسی را روی شبیه‌ساز اختصاصی نصب می‌کند، دادهٔ همان برنامه را پاک می‌کند و مسیر شروع سرد، لمس، وقفه و بازگشت را با ساعت واقعی اجرا می‌کند.

```bash
ANDROID_SERIAL=emulator-5554 node scripts/test-harbor-android.mjs android/app/build/outputs/apk/debug/app-debug.apk /tmp/harbor-evidence
```

منطق بازی در `src/harbor`، مدل اقتصادی در `src/lib/opening-industry.ts`، جدول‌های مرجع در `src/data/reopening` و تصاویر نسخهٔ موبایل در `public/harbor` هستند. جزئیات طراحی و مهاجرت این نسخه در یادداشت انتشار آمده است. [یادداشت نسخهٔ ۱٫۰٫۰](strait-of-hormuz-game-docs/release-notes/v1.0.0-test.md)
