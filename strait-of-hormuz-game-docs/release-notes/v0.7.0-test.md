## نسخهٔ آزمایشی اندروید ۰٫۷٫۰

- ذخیره و بازیابی وضعیت نبرد، پشتیبان محلی و انتقال فایل ذخیره اضافه یا اصلاح شدند.
- پیشرفت کمپین از چالش و بی‌پایان جدا شد. ۲۹ مأموریت و راهنمای آمادگی دفاع مسیر پیشرفت را روشن‌تر می‌کنند.
- درآمد آفلاین، هدیهٔ روزانه، بازپرداخت ساخت و ارتقای برجک و هدف اسکورت اصلاح شدند.
- انیمیشن‌های ساختمان پس از بازتولید ۵۵ مدل به صحنه برگشتند. زمان‌بندی افکت شلیک و رفتار هنگام قطع نمای سه‌بعدی اصلاح شدند.

این APK با کلید Debug برای نصب آزمایشی ساخته شده و به Android 6.0 یا بالاتر نیاز دارد. آزمایش عملکرد، حرارت و قابلیت‌های بومی روی گوشی واقعی باقی مانده است. نسخه رایگان و بدون تبلیغ یا خرید درون‌برنامه‌ای است. هدف نگهداشت روز بیستم هنوز با دادهٔ واقعی سنجیده نشده است.
