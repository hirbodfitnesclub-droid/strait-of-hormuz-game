## بازتولید

- در ریشهٔ بستهٔ طراحی، `python3 qa/run_all.py` هر ۲۹ fixture را با ۱۷ برنامه بازتولید می‌کند. دفتر SHA بسته شامل ۹۴ فایل بود. آزمون اختیاری هش پژوهش‌های REA به آرشیو جداگانهٔ مطالعات نیاز دارد.
- در ریشهٔ مخزن، `npm run verify` هم آزمون‌های رگرسیون ۰٫۷٫۴ و هم `npm run test:opening` را اجرا می‌کند. `npm run build:android` خروجی Next را به Capacitor می‌دهد. `bash android/gradlew -p android assembleDebug` با Java 21 و Android SDK، فایل نصب اندروید را می‌سازد.
- برای اجرای ۱۸۰ ثانیه روی محتوای یک APK مشخص، `REOPENING_APK=/path/game.apk REOPENING_EVIDENCE=/tmp/reopening node scripts/test-reopening-apk.cjs natural` را اجرا کنید. سناریوهای `paid`، `bank` و `poor` خرید نقدی، برداشت و کمبود بودجه را می‌سنجند. سناریوهای مالی از ذخیره‌های ثبت‌شدهٔ مسیر طبیعی استفاده می‌کنند. برای `legacy` متغیر `REOPENING_LEGACY_SAVE` مسیر ذخیرهٔ ۰٫۷٫۴ را می‌گیرد. این اجرای مرورگری از فایل‌های داخل APK استفاده می‌کند.
- اجرای دستی گردش کار `Game quality` فایل نصب را نگه می‌دارد و دو آزمون موازی دارد. یکی APKهای مبنا و نامزد را روی یک دستگاه مجازی اندروید نصب می‌کند و از WebView، تصویر صفحه و دفتر رویداد می‌گیرد. دیگری جریان‌های رگرسیون موبایل را روی فایل‌های استخراج‌شده از همان APK اجرا می‌کند.
- روی گوشی متصل، `scripts/profile-android.py --help` گزینه‌های ثبت مدل، نسخه، WebView، روشنایی، فریم و حرارت را نشان می‌دهد. خط مبنای سخت‌افزاری به نصب هر دو نسخه و اجرای صحنهٔ یکسان روی همان گوشی نیاز دارد.
